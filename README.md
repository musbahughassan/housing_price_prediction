# Housing Price Prediction Model

A machine learning project that predicts **median house value** for California districts from census-style features such as location, house age, income, and proximity to the ocean. The notebook trains and compares four regression models (XGBoost, AdaBoost, Random Forest, CatBoost) and saves the best-performing one for reuse.

## Dataset

- **File:** `1553768847_housing.xlsx` (not included in this repo, place it in the project root)
- **Size:** 20,640 rows, 10 columns
- **Target:** `median_house_value`

| Column | Type | Description |
|---|---|---|
| `longitude` | float | Block group longitude |
| `latitude` | float | Block group latitude |
| `housing_median_age` | int | Median age of houses in the block |
| `total_rooms` | int | Total rooms in the block |
| `total_bedrooms` | float | Total bedrooms in the block (207 missing values) |
| `population` | int | Block population |
| `households` | int | Number of households |
| `median_income` | float | Median household income |
| `ocean_proximity` | categorical | Distance category to the ocean (5 classes) |
| `median_house_value` | int | **Target:** median house value |

## Workflow

1. **Load data** from the Excel file with pandas.
2. **Handle missing values:** the 207 missing `total_bedrooms` entries are filled with the column mean.
3. **Encode categoricals:** `ocean_proximity` is converted to integers with `LabelEncoder`.
4. **Explore:** a correlation matrix and heatmap (seaborn) are used to inspect feature relationships.
5. **Split:** 80% train / 20% test (`random_state=42`).
6. **Train and evaluate** four models using R² (and MAE for XGBoost) on the test set, plus 5-fold cross-validation.
7. **Persist** the trained XGBoost model with `joblib`.

## Results

| Model | Test R² | 5-fold CV R² (mean) |
|---|---|---|
| **XGBoost** | **0.821** | 0.637 |
| Random Forest | 0.810 | 0.512 |
| AdaBoost | 0.376 | 0.289 |
| CatBoost | not computed* | 0.669 |

XGBoost test-set **MAE: ~$32,176**.

\*In the notebook, CatBoost was fit but its test-set predictions were never scored (the predictions variable was overwritten), so only its cross-validation scores are available.

**Takeaways**

- XGBoost and Random Forest score best on the held-out test set; AdaBoost lags well behind.
- Cross-validation scores are noticeably lower than test scores for every model and vary a lot between folds (e.g. Random Forest ranges from 0.11 to 0.70). This suggests performance is sensitive to how the data is split. Since the rows appear ordered geographically, the unshuffled CV folds likely contain very different regions. Using `KFold(shuffle=True)` would give a fairer estimate.
- CatBoost has the best mean CV score, so it is worth evaluating on the test set as well.

## Usage

1. Place `1553768847_housing.xlsx` in the same folder as the notebook.
2. Launch Jupyter and open the notebook:

   ```bash
   jupyter notebook housing_price_prediction_model.ipynb
   ```

3. Run all cells top to bottom.

### Using the saved model

Running the notebook produces `xgb_trained_model`. To make predictions later:

```python
import joblib
import pandas as pd

model = joblib.load("xgb_trained_model")

# X_new must have the same columns, order, and encoding as the training data:
# longitude, latitude, housing_median_age, total_rooms, total_bedrooms,
# population, households, median_income, ocean_proximity (label-encoded)
predictions = model.predict(X_new)
```

> Note: the `LabelEncoder` is not saved, so new data must use the same integer mapping for `ocean_proximity` (alphabetical: `<1H OCEAN`=0, `INLAND`=1, `ISLAND`=2, `NEAR BAY`=3, `NEAR OCEAN`=4, assuming the standard category names).

## Possible Improvements

- Use a `Pipeline` (imputer, encoder, model) and save the whole thing so preprocessing travels with the model.
- Replace label encoding with one-hot encoding, since `ocean_proximity` has no natural order.
- Engineer features such as rooms per household, bedrooms per room, and population per household.
- Tune hyperparameters (`GridSearchCV` / `RandomizedSearchCV` / Optuna) instead of using defaults.
- Use shuffled K-fold cross-validation and report RMSE alongside R² and MAE.
- Score CatBoost on the test set for a complete comparison.
